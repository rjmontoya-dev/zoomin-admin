Contribution Guidelines ​

We welcome contributions from the community. To ensure that all contributions are of high quality and follow the project's standards, please read the following guidelines before submitting a pull request.

Bug Reports ​

If you find a bug, please open an issue on GitHub and provide a detailed description of the problem, including steps to reproduce it.

Feature Requests ​

If you have an idea for a new feature, please open an issue on GitHub and provide a detailed description of the feature and why it would be a valuable addition to the project.

Pull Requests ​

  1. Fork the repository: Fork the repository to your own GitHub account.
  2. Create a new branch: Create a new branch for your changes: git checkout -b my-new-feature.
  3. Make your changes: Make your changes and commit them with a clear and concise commit message.
  4. Push your changes: Push your changes to your forked repository: git push origin my-new-feature.
  5. Open a pull request: Open a pull request from your forked repository to the main repository.

Pull Request Checklist ​

  • [ ] All tests pass.
  • [ ] The code follows the project's coding standards.
  • [ ] The documentation has been updated to reflect the changes.
